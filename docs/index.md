# Hero-Tools Documentation

HeroSDK is a software development kit for heterogeneous RISC-V platforms using
OpenMP target offload.

For the staged local Occamy work on `occamy-minimal-bootstrap`, start with the
[Local Occamy Milestone Roadmap](local-occamy-roadmap.md).

```text
M0  control path
M1  shared-memory path
M2  runtime and numerical kernel
M3a live mailbox target launch
M3b Linux/OpenMP replay freeze
M4  real FPGA bring-up
```

General upstream-oriented documentation remains available under Getting
Started, Software, and Platforms.
